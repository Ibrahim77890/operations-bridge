Now exposing the cloudflare tunneling our bash bridge script
sudo mkdir -p --mode=0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | \
sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main" | \
sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt-get update
sudo apt-get install cloudflared
cloudflared --version

Now remember to connect Apps Script to Cloudflare tunnel which exposes bridge.sh api implementation of our bash engine, following are the steps:
1) Export OPSBRIDGE_KEY
2) Start ./bridge.sh
3) From other terminal, start cloudflare service
4) Then use the key and the url generated by cloudflare appended with /execute and save them to Apps Script properties variables and then test, so it will be connected securely
